# Volleyball Stats Recorder

バレーボールの試合スタッツを iPad / スマホで記録する Web アプリです。
インストール不要、登録不要、完全オフライン動作。

🌐 **アプリを開く**: https://slothfront.github.io/volleyball-stats/

---

## なぜ作ったか

高校教師として高校女子バレー部を指導するなかで、試合のデータを記録・分析できるツールが欲しくなりました。
既存の高機能ソフトは PC 前提・有料・操作が複雑で、部活レベルでは使いづらい。さらに調べてみると、機能が充実しているものはほとんどが英語など海外製のアプリで、日本語に完全対応した使いやすいツールがほぼ存在しないことに気づきました。

そこで、マネージャーが iPad でタップだけで日本語のまま記録できる 試合記録ツールを自分で作ることにしました。を自分で作ることにしました。

## できること

### 記録
- 自エース / 自スパイク決定 / 自ブロック決定 / 相手ミス
- 被サービスエース / 被スパイク失点（ゾーン記録）
- 自サーブミス / 自スパイクミス / その他自ミス / 自反則
- スパイク試行（ラリー継続中）
- 9 ゾーンへの落下位置を記録
- **失点した球と自チームの決定球を点で記録**（設定「POINTS ON COURT — HOW DEEP」で 3 段階。スパイク決定・サービスエースは「誰が・どこから打って・どこに決まったか」を 1 画面で）
  - ゾーン：9 面から選ぶ（従来）
  - 点：コート図で打点→落下点をタップ（コート外も可）。強打／軟打も記録。ゾーンは座標から自動算出
  - 点＋反応：さらに「触った・反応した人」（複数可）／「誰も動けず」を記録。被スパイク失点とディグミス（被エースとレシーブミス）は 1 つのボタンになり、反応が 1 人ならその人のミス、2 人以上・誰も動けずは被スパイク失点（被エース）として自動で振り分ける。「ディグ↑（上げた）」ボタンで拾った本数も選手別に数える
  - 横持ちのコート図は**ベンチから見た向き**（画面の下＝ベンチ側。自コートの左右はセットごとに自動で入れ替わる）
- **サーブ順を試合中に記入**（スタメン入力を省略。自チームのサーブになるたびに「次のサーバーは？」と聞き、6 人そろえば 2 周目から自動）。サーブ順が乱れたときや交代は、サーバー名をタップして選び直す（別の位置の選手＝入れ替え／ベンチの選手＝交代）。横持ちでもローテ表のタップで交代できる
- ローテーション自動管理（5-1 システム想定）
- リベロ対応
- 詳細記録モード（ミス内訳・反則種別を選択可）

### 分析
- セット / 試合のサマリー（得点内訳・SO% / PS%）
- ローテーションごとのサイドアウト率・ブレイク率
- 9 ゾーンヒートマップ（タイプ別 × ローテ別フィルタ）／点で記録したものは**点図**（打点の小さな白丸→線→落下点の丸。失点は強打＝赤実線・軟打＝橙破線・誰も動けず＝白抜き、自チームの決定球は緑）。自スパイク決定は選手別に絞り込める
- 守備（ディグ）表：選手別の「上げた」「反応して失点」「上げた率」、誰も動けなかった失点数、失点した球の強打／軟打の内訳
- 個人スタッツ（サーブ効果率・スパイク効果率含む）
- ミス内訳（詳細モード時）

### データ管理
- 試合データは端末の localStorage に保存（オフライン動作）
- CSV エクスポート（ラリーログ / サマリー）
- JSON バックアップ・インポート
- スタメンプリセット保存
- ロスター（チームメンバー）の永続保存

## 使い方

### 初回

1. 上記 URL を iPad / スマホ / PC のブラウザで開く
2. iPad / iPhone なら Safari の「ホーム画面に追加」でアプリのように使える
3. 一度開けばオフラインでも動作する

### 試合記録の流れ

1. **新しい試合をはじめる**
2. 対戦相手と試合日を入力
3. 出場メンバーを入力（次回以降は「保存」で自動ロード）
4. スタメン 6 人を P1〜P6 に配置（「サーブ順は試合中に記入する」にチェックすれば省略可）
5. 最初のサーブ権を選択
6. 試合中、得点が動くたびに該当ボタンをタップ
7. セット終了 / 試合終了の操作で集計画面へ

### データの保存

- 端末の localStorage に保存されるため、**ブラウザの履歴 / キャッシュをクリアすると消えます**
- 試合ごとに JSON バックアップを取ることを推奨
